方法（B12：A 堆逐模块 → 逐子族，B/C 堆逐模块判可移植性）：

1. **子族判词**：`platform/` 路径先按 `PLATFORM_RULES` 的路径片段归到 `lp/*`/`pf/*` 等子族，
   每个子族一条判词，写清用户可见行为在本仓落在哪个文件、缺什么；判词里引用的本仓路径由门禁逐个核对**真实存在**。
2. **模块兜底**：没有子族规则的包仍归 `module/<模块>` —— A 堆按 `[ ]` 写明「其余子包逐类判定待办」，
   B/C 堆按 `[-]` 写可移植性理由（A/B/C 分堆见 `MODULE_HEAP`）。
3. **机械修正**：上游测试源码（`testSources`/`tests/`）判 `[-]`；`gen/`/`resources/`/`testEntities/` 这类生成物与夹具判 `[-]`；
   子族判 `[~]` 而类本身是 Swing 组件本体的判 `[-]`（行为由本仓 DOM 落点承担）。
4. 机械信号由 `scripts/verdict_signals.py` 产出（行数 / Swing / 平台专属 / 在 TaoCode 里出现过没有），每行的档位都能复算。
