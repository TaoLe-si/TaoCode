## 4. 反向验证（新门禁的三步，数字）

注入两处违规（同时），跑 `node --test tests/run-startup-focus.test.mjs`：

   `takeFocus: activate && focus`（删掉上游 `RunContentManagerImpl.kt:451-457` 的「没有焦点所有者 ⇒ 强制补真」）；
2. `:137` 的 `canReuseView` 去掉 `!view.running`（等于允许复用**在跑**的标签，违 `:854-856`）。

⇒ **9 tests / 7 pass / 2 fail**，红的正是
`判据三：设置开但实例已有活动页 ⇒ 夺焦照旧，标签看不在跑才复用` 与
`边界一（会失败的用例）：设置关，但此刻应用没有焦点所有者 ⇒ 强制夺焦`。

撤掉两处注入后复跑 ⇒ **9 tests / 9 pass / 0 fail**（已复绿，见 §3 第一行）。

另外两处反向断言是**常驻**的（不需要临时注入）：
`边界一` 里 `decideRunStartupFocus({...OFF, focusOwnerMissing: true}).takeFocus === false`
（证明「焦点缺失」不许越过 `:439-441` 那个 return）、`边界二` 里
`selectContentWhenAdded: false` 且非选中复用格 ⇒ `selectView === false`。
